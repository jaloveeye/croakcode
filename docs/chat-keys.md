# Open WebUI 같은 대화 프로그램에서 쓰기

croakcode 로그인 키는 croakcode에서만 쓸 수 있다. Open WebUI 같은 대화 프로그램에는 대화 전용 키를 만들어 쓴다. 대화 프로그램은 각자의 PC에서 돌린다.

## 키 만들기

1. croakcode에서 `/login`으로 로그인한다.
2. `/chatkey`를 입력하고 "새 키 만들기"를 고른다.
3. 키 이름과 유효 기간을 넣는다. 기간은 비워 두면 30일이고, 최대 90일이다.
4. 화면에 게이트 주소와 키가 나온다. 키는 클립보드에도 복사된다.

키는 이때 한 번만 보인다. 잃어버리면 지우고 새로 만든다. 한 사람이 열어 둘 수 있는 키는 5개다.

## 대화 프로그램에 넣기

- Open WebUI의 OpenAI API 연결에 게이트 주소(`https://<게이트>/v1`)와 키를 넣는다.
- 대화 프로그램이 게이트 인증서를 신뢰해야 연결된다. 인증서는 게이트의 `https://<게이트>/download/ca.crt`에서 받는다. croakcode를 설치한 PC에는 `~/.config/croak/ca/ca.crt`로도 있다.
- 받은 인증서의 SHA-256 지문을 `/chatkey` 화면과 다운로드 페이지의 값과 비교한다. 비교 명령은 다운로드 페이지에 있다.
- 인증서는 그 대화 프로그램에만 등록한다. Windows나 브라우저 전체의 신뢰 목록에는 넣지 않는다.
- Open WebUI를 Docker로 쓰면 이미지에 등록한다. 방법은 다운로드 페이지(`https://<게이트>/download/#chat`)에 있다.

## 제한

- 이 키로는 도구를 쓸 수 없다. 웹 검색, 코드 실행 같은 도구를 켠 요청은 게이트가 거부한다. 도구가 필요한 작업은 croakcode에서 한다.
- 개인정보 마스킹, 비밀정보 검사, 기록은 croakcode와 같다.
- 등급이나 비밀번호가 바뀌면 키가 모두 폐기된다. 다시 만든다.
- 키를 다른 사람에게 주지 않는다. 쓰지 않는 키는 `/chatkey`에서 지운다.
