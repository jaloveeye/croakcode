# 전체 시험 계획

- **날짜**: 2026-11-10
- **대상**: `master` 5b8eba9 (PR #53 병합 시점)
- **목적**: 설치부터 실제 사용, 실패 복구까지 사용자가 겪는 흐름 전체를 시험한다.
- **결과 기록**: `docs/superpowers/evidence/2026-11-10-full-test.md`

## 1. 원칙

- 운영 게이트와 실제 모델(Qwen 27B)을 쓴다. 모델 사용은 1~2시간 안에서 끝낸다.
- 실행 허가 필수(`require_permits`)는 로컬 Docker 게이트에서만 켠다. 운영 게이트 설정은 바꾸지 않는다.
- 개인정보와 비밀값은 가짜 값만 쓴다. 비밀 파일은 시험 폴더 안에 가짜로 만든다.
- 회사 내부 문서는 쓰지 않는다. HWP 시험에는 rhwp 저장소의 공개 시험 문서를 쓴다.
  - 쓰는 문서는 `samples/hwpx/hancom-hwp/activity_report.hwp`다. 2쪽이고 표가 2개 있다.
  - 메모는 사본에만 쓴다.
- 게이트 주소 같은 운영 정보는 기록에 남기지 않는다.
- 찾은 문제는 PR로 고친다. 고친 뒤 해당 항목을 다시 시험한다.

## 2. 시험 항목

### A. 설치와 첫 사용

깨끗한 HOME에서 설치 스크립트로 설치하고 처음 실행한다.

| # | 확인 |
|---|---|
| A1 | `install-croakcode.sh`가 오류 없이 끝나고 실행 파일, 설정 링크, 환경 파일이 생긴다 |
| A2 | 환경 파일 권한이 600이다 |
| A3 | 첫 실행에서 provider 연결 화면 없이 바로 입력창이 뜬다 |
| A4 | 로그인 뒤 첫 질문에 답이 온다 |
| A5 | `--uninstall`이 설치한 것만 지운다 |

### B. 핵심 기능 (운영 게이트, 실제 모델)

| # | 작업 |
|---|---|
| B1 | 작은 프로젝트에서 함수 하나를 고치고 시험을 돌린다 |
| B2 | 읽지 않은 파일 수정이 거부되고, 모델이 읽은 뒤 다시 고친다 |
| B3 | 같은 파일 다시 읽기가 안내로 바뀐다 |
| B4 | HWP 문서를 읽고 표 내용을 요약한다 |
| B5 | HWP 사본에 메모를 단다 |
| B6 | webfetch로 웹 페이지를 읽고 질문에 답한다 |
| B7 | 할 일 목록을 만들고 진행 상태를 바꾼다 |
| B8 | 하위 에이전트에게 조사를 맡긴다 |
| B9 | 숨긴 도구를 `tool_search`로 찾아 `tool_call`로 부른다 |
| B10 | 긴 대화에서 압축이 일어나고 이어서 작업한다 |
| B11 | 세션을 끝내고 `-s`로 이어서 연다 |
| B12 | 가짜 개인정보가 모델에 가려져 전달된다 |

### C. TUI

tmux로 자동 확인하고, 마지막에 사용자가 점검표로 직접 확인한다.

| # | 확인 |
|---|---|
| C1 | 시작 화면의 로고와 개구리, "based on opencode" 표시 |
| C2 | 스크롤바가 보이고 긴 대화에서 움직인다 |
| C3 | 위로 올리면 "맨 아래로" 버튼과 "새 내용"이 뜬다 |
| C4 | "복사"를 누르면 그 답변만 복사된다 |
| C5 | 답변 중 ctrl+s로 끼어들면 답변이 멈추고 새 메시지가 들어간다 |
| C6 | `/btw` 곁질문 답이 창으로 뜨고 세션에 남지 않는다 |
| C7 | 위험한 bash 형태에서 확인 창이 뜬다 |
| C8 | 종료 화면에 로고와 이어 열기 명령이 보인다 |

### D. 실행 허가 (로컬 Docker 게이트)

| # | 확인 |
|---|---|
| D1 | 허가 필수 상태에서 허가를 받은 도구만 실행된다 |
| D2 | 허가 없이, 만료된 허가로, 다른 도구의 허가로 실행하면 거부되고 감사 기록에 남는다 |
| D3 | 등급(tier)이 막은 도구는 허가를 받을 수 없다 |
| D4 | `/net-off` 뒤에는 네트워크 도구가 막힌다 |

### E. 성능

| # | 측정 |
|---|---|
| E1 | 새 세션의 첫 응답 시간 |
| E2 | 캐시가 식은 뒤(새 프로젝트)의 첫 응답 시간 |

### F. 실패와 복구

| # | 상황 |
|---|---|
| F1 | 게이트가 응답하지 않을 때 오류가 보이고 프로그램이 멈추지 않는다 |
| F2 | 토큰이 만료되면 갱신하고 이어서 동작한다 |
| F3 | 모델 오류(5xx, 빈 답)에 다시 요청하거나 오류를 보여 준다 |
| F4 | esc로 답변을 멈추면 앞부분이 남고 다음 질문이 된다 |
| F5 | 답변 도중 프로그램을 끄고 다시 열면 세션이 이어진다 |
