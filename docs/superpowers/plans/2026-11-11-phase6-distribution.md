# Phase 6: 배포, 버전, 업데이트

- **날짜**: 2026-11-11
- **상태**: 계획
- **배경**: 사용자 PC 3대는 croakcode 저장소에 접근할 수 없다. 운영체제는 Windows(WSL), Windows, macOS, Linux가 모두 있다. 모든 등급에 `require_permits`를 켜려면 모든 PC가 최신 croakcode를 써야 한다.
- **사용자 결정**:
  - 설치 파일은 게이트에서 받는다.
  - 버전을 관리한다.
  - 업데이트를 감지하고, 필수 업데이트와 선택 업데이트를 나눈다.
  - 필수 업데이트를 하지 않으면 croakcode를 쓸 수 없다.

## 1. 확인한 사실

- upstream 빌드 스크립트(`script/build.ts`)는 Linux, macOS, Windows의 x64와 arm64 실행 파일을 만든다.
- 이 PC용 실행 파일은 1분 걸려 만들어졌고 크기는 144MB다.
- 그 실행 파일로 TUI를 띄우자 croak 플러그인이 모두 동작했다. 로그인 상태가 보였고, 허가를 받아 read가 실행됐다.
- 남은 문제가 두 가지 있다.
  - 실행 파일 이름이 `opencode`다.
  - 버전이 `0.0.0-<브랜치 이름>-<시각>`이다.

## 2. 구성

| 부분 | 내용 |
|---|---|
| 버전 | `MAJOR.MINOR.PATCH`. `master`에 태그 `vX.Y.Z`를 달면 그 버전으로 빌드한다 |
| 빌드 | 태그 하나로 다섯 가지 실행 파일을 만든다(linux x64와 arm64, darwin x64와 arm64, windows x64). 이름은 `croakcode`다. 제품 설정(`.croakcode`)을 함께 묶는다 |
| 배포 목록 | 게이트에 `manifest.json`을 둔다. 내용은 최신 버전, 최소 버전, 파일마다의 SHA-256, 바뀐 내용 요약이다 |
| 내려받기 | 게이트가 `/download/` 아래로 실행 파일, 설치 스크립트, CA 인증서를 내준다 |
| 설치 | Linux, macOS, WSL은 `install.sh`, Windows는 `install.ps1`이다. 명령 한 줄로 실행 파일, 설정, 실행 명령을 설치한다 |
| 업데이트 | `croakcode upgrade`가 게이트에서 새 버전을 받아 SHA-256을 확인하고 바꾼다 |

## 3. 업데이트 정책

`manifest.json`의 두 값으로 정한다.

| 값 | 뜻 |
|---|---|
| `latest` | 최신 버전. 이보다 낮으면 선택 업데이트를 알린다 |
| `minimum` | 최소 버전. 이보다 낮으면 필수 업데이트다 |

| 경우 | croakcode가 하는 일 |
|---|---|
| 최신 | 아무것도 하지 않는다 |
| 선택 업데이트 | 시작 화면과 사이드바에 "새 버전 X.Y.Z · croakcode upgrade"를 보인다. 계속 쓸 수 있다 |
| 필수 업데이트 | 시작할 때 업데이트를 안내하고 멈춘다. `croakcode upgrade`만 실행할 수 있다 |

릴리스마다 필수인지 정한다. 보안 수정과 게이트 연동이 바뀌는 릴리스는 필수다. 필수로 하려면 `minimum`을 그 버전으로 올린다.

### 강제하는 곳

PC 쪽 확인만으로는 우회할 수 있다. 그래서 게이트가 최종으로 막는다.

- croakcode는 모든 요청에 `x-croak-client-version` 머리글을 붙인다.
- 게이트는 이 머리글이 없는 요청을 거부한다(HTTP 426). 버전이 `minimum`보다 낮은 요청도 거부한다. 거부 문구는 업데이트 명령을 알려 준다.
- 로그인 서비스도 같은 기준으로 로그인을 거부한다.

## 4. 작업

### Task 1. 버전과 이름

- **명세**: 태그 `vX.Y.Z`에서 버전을 읽어 빌드에 넣는다. 실행 파일 이름을 `croakcode`로 바꾼다. 태그가 없는 빌드는 `X.Y.Z-dev.<커밋>`로 한다. 첫 버전은 `0.6.0`이다(Phase 6).
- **수용**: `croakcode --version`이 태그 버전을 보인다.

### Task 2. 배포 묶음

- **명세**: 스크립트 하나로 다섯 가지 실행 파일을 만든다. 실행 파일마다 `.croakcode` 제품 설정을 넣은 압축 파일과 SHA-256을 만든다. `manifest.json`을 만든다. 게이트에 올리는 일은 `deploy.sh`와 같은 방식으로 한다.
- **수용**: 다섯 압축 파일과 `manifest.json`이 만들어진다. 각 실행 파일이 그 운영체제에서 `--version`을 통과한다. 이 PC에서는 linux x64를 직접 확인하고, 나머지는 빌드 스크립트의 교차 빌드 결과로 확인한다.

### Task 3. 게이트의 내려받기 경로

- **명세**: Caddy가 `/download/`를 정적 파일로 내준다. 로그인 없이 받을 수 있다. 실행 파일과 설정에는 비밀값이 없기 때문이다. 내려받기 파일은 저장소 밖의 서버 폴더에 둔다.
- **수용**: 설치 스크립트, `manifest.json`, CA 인증서, 압축 파일을 HTTPS로 받을 수 있다.

### Task 4. 설치 스크립트

- **명세**: `install.sh`(Linux, macOS, WSL)와 `install.ps1`(Windows)이다.
  - 게이트 주소와 CA 인증서를 저장한다.
  - 운영체제와 CPU에 맞는 파일을 받아 SHA-256을 확인한다.
  - 실행 파일을 사용자 폴더에 두고 PATH에 넣는다. 제품 설정을 `~/.croakcode`에 푼다.
  - CA 인증서는 관리자가 알려 준 지문으로 확인한다. 처음 받을 때는 아직 CA를 믿을 수 없기 때문이다.
- **수용**: 빈 계정에서 명령 한 줄로 설치하고, 실행하고, `/login`하면 쓸 수 있다. 네 가지 운영체제 각각에서 확인한다.

### Task 5. 업데이트 감지와 `croakcode upgrade`

- **명세**:
  - 시작할 때 게이트의 `manifest.json`을 읽는다. 하루 한 번만 읽고 결과는 저장해 둔다.
  - 선택 업데이트는 알리고, 필수 업데이트는 멈춘다(3절).
  - `croakcode upgrade`는 새 실행 파일과 설정을 받아 SHA-256을 확인한 뒤 바꾼다. Windows는 실행 중인 파일을 바꿀 수 없으므로 다음 실행 때 바꾼다.
- **수용**: 버전을 낮춰 빌드한 실행 파일로 세 경우(최신, 선택, 필수)를 재현한다.

### Task 6. 게이트의 최소 버전 강제

- **명세**: croakcode가 `x-croak-client-version`을 보낸다. 게이트와 로그인 서비스는 `minimum`보다 낮은 버전을 426으로 거부한다. 기준은 `manifest.json`의 `minimum`과 같은 값을 쓴다.
- **수용**: 낮은 버전과 머리글이 없는 요청이 거부되고, 최신 버전은 통과한다. 거부 문구에 업데이트 명령이 있다.

### Task 7. 첫 배포와 `require_permits`

- 순서:
  1. `0.6.0`을 게이트에 올린다.
  2. 다른 PC 3대가 설치한다.
  3. `minimum`을 `0.6.0`으로 둔다.
  4. 모든 등급에 `require_permits: true`를 켠다.
- 소스로 설치한 이 PC는 `install.sh`로 바꾼다.

## 5. 정할 것

| 항목 | 선택지 | 추천 |
|---|---|---|
| 자동 업데이트 | 알리기만 / 필수만 자동 / 모두 자동 | 필수만 자동. 필수 업데이트는 시작할 때 묻고 바로 받는다. 선택 업데이트는 알리기만 한다 |
| HWP 도구(rhwp) | 함께 배포 / 따로 설치 / 빼기 | 따로 설치. rhwp는 388MB이고 HWP를 쓰지 않는 사용자도 있다 |
| Windows 네이티브 | 이번에 지원 / WSL만 지원 | 이번에 지원. 사용자 결정에 네 가지 운영체제가 모두 들어 있다. bash 도구와 경로 처리 시험이 더 필요하다 |

## 6. 위험

- **Windows 네이티브**: croakcode의 셸 도구, 비밀 경로 검사, HWP 경로 변환을 Windows에서 따로 시험해야 한다.
- **macOS**: 서명하지 않은 실행 파일은 처음 실행할 때 보안 경고가 뜬다. 설치 스크립트가 격리 속성을 지운다.
- **실행 파일 크기**: 144MB다. 다섯 가지면 약 720MB가 게이트 서버 공간을 쓴다. 이전 버전은 두 개만 남긴다.
