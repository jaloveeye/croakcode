# croakcode 업데이트

croakcode는 시작할 때 게이트의 배포 목록을 확인한다. 확인 결과는 하루 동안 저장한다. 그 사이에는 저장한 결과를 쓴다. 게이트에 연결할 수 없으면 마지막으로 확인한 결과를 쓴다.

최신 버전이 있으면 시작 화면과 사이드바에 알린다. 다음 명령으로 업데이트한다.

```sh
croakcode upgrade
```

최소 버전보다 낮으면 시작할 때 업데이트를 묻는다. 동의하면 새 파일을 받아 설치한다. 거절하면 프로그램이 종료된다. 터미널에서 답할 수 없는 경우에도 종료한다.

다운로드에는 설치할 때 저장한 CA 인증서를 사용한다. 배포 묶음의 크기와 SHA-256을 확인한 뒤 설치한다. 기존 제품 설정은 `~/.croakcode.update-backup-...`에 보관한다.

Windows에서는 실행 중인 파일을 바로 바꿀 수 없다. 업데이트를 받은 뒤 croakcode를 다시 실행한다. 실행 명령이 새 파일을 적용한다. 다른 croakcode 프로세스가 파일을 사용 중이면 모두 닫고 다시 실행한다.

게이트에 연결하지 못하고 저장된 결과도 없으면 버전을 확인하지 못한다. 게이트에서 최소 버전을 강제하는 작업은 Phase 6의 다음 단계에서 한다.
